## 🇬🇧 English Profile

Developer based in Andalucia, Spain. I build web apps, automation infrastructure, anti-detection systems and forensic tools — mostly things that need to work reliably in hostile environments.

Currently working on browser automation that blends in, voice biometrics with deepfake detection, and bot management infrastructure for contact center environments.

### 🚀 Featured Projects

- [**Phantomime**](#) — Humanized browser automation library with full anti-detection stack. TLS fingerprinting, Canvas/WebGL spoofing, human-like behavior simulation. Python + Playwright + curl-cffi.
- [**VoiceID**](#) — Forensic-grade voice comparison and deepfake detection system. Compares two audio samples for speaker identity match and flags AI-generated audio. FastAPI + SpeechBrain + Wav2Vec2 + Redis + Docker.
- [**BotFarm**](#) — Docker/Podman-based Python bot management platform with FastAPI + React dashboard. AES-256-GCM credential encryption, JWT auth, real-time log streaming. Built for contact center automation at scale.
- [**tornoBot**](#) — ZKTeco biometric turnstile monitoring and sync system. Multi-device threading, DST-safe scheduling, UDP-only ZK protocol, MySQL event storage.
- [**CronShepherd**](#) — SSH-only cron manager built in PHP + Alpine.js. Manage remote crontabs from a web UI without exposing shell access.
